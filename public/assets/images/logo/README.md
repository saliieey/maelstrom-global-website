# Logo Assets

This folder is for company logo images.

## Folder Structure
```
public/
  assets/
    images/
      logo/
        ├── logo.svg (or logo.png) - Main logo
        ├── logo-white.svg - White version for dark backgrounds
        ├── logo-icon.svg - Icon version
        └── favicon.ico - Favicon
```

## Instructions
1. Place your company logo files in this folder
2. Supported formats: SVG (preferred), PNG, JPG
3. For best quality, use SVG format
4. Once you've added the logo, inform the developer to update the navigation component

## Current Status
- Logo placeholder will be replaced once you provide the logo files
- Navigation component is ready to accept logo path: `/assets/images/logo/logo.svg`
