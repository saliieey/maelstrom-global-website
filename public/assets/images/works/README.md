# Works Images Directory

This directory contains images for the "Our Works" section.

## Structure

Each work should have two images:
- `{work-slug}-1.jpg` - First image (left side on desktop)
- `{work-slug}-2.jpg` - Second image (right side on desktop)

## Example

For a work with slug "amend-dental":
- `amend-dental-1.jpg`
- `amend-dental-2.jpg`

## Image Requirements

- **Format**: JPG or PNG
- **Aspect Ratio**: 3:4 (portrait orientation recommended)
- **Recommended Size**: 600x800px minimum
- **Optimization**: Images should be optimized for web (compressed but maintaining quality)
