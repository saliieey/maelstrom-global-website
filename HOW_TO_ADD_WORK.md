# How to Add a Work in WordPress - Step by Step

## 📝 Where Each Field is Located

When you click **"Works" → "Add New"**, you'll see this form:

---

## 🎯 Top Section (Main Editor)

### **Title Field** (at the very top)
- **Location:** Big text box at the top of the page
- **Label:** "Add title" or "Enter title here"
- **Example:** "Partnering with Amend Dental"
- **This is the main title that appears on your website**

---

## 📦 Middle Section - "Work Details" Box

**Look for a box titled "Work Details"** - this contains all the custom fields:

### 1. **Description/Tagline**
- **Location:** Inside "Work Details" box, first field
- **Label:** "Description/Tagline"
- **Type:** Text input box
- **Example:** "Where modern care meets confident smiles"
- **This appears below the title on your website**

### 2. **Image 1 URL**
- **Location:** Inside "Work Details" box
- **Label:** "Image 1 URL"
- **Type:** Text input box + "Select Image" button
- **How to add image:**
  1. Click the **"Select Image"** button
  2. WordPress media library will open
  3. Choose an image or upload a new one
  4. Click **"Select"** or **"Use this image"**
  5. The URL will automatically fill in
- **This is the main image shown on your website**

### 3. **Image 1 Alt Text**
- **Location:** Right below "Image 1 URL"
- **Label:** "Image 1 Alt Text"
- **Type:** Text input box
- **Example:** "Amend Dental Campaign Image"
- **This is for accessibility (screen readers)**

### 4. **Image 2 URL** (Optional)
- **Location:** Below Image 1 Alt Text
- **Label:** "Image 2 URL"
- **Type:** Text input box + "Select Image" button
- **Optional:** You can leave this blank if you only have one image

### 5. **Image 2 Alt Text** (Optional)
- **Location:** Below Image 2 URL
- **Label:** "Image 2 Alt Text"
- **Optional:** Only fill if you added Image 2

### 6. **Featured Checkbox**
- **Location:** Below Image 2 Alt Text
- **Label:** "Featured" with checkbox
- **Text:** "Show on home page"
- **Action:** ✅ Check this box to show on home page

### 7. **Order**
- **Location:** Last field in "Work Details" box
- **Label:** "Order"
- **Type:** Number input box
- **Example:** 1, 2, 3, etc.
- **Lower numbers appear first**

---

## 📂 Right Sidebar

### **Category**
- **Location:** Right sidebar, under "Categories" section
- **Type:** Checkboxes
- **Options:**
  - Social Media
  - Performance Marketing
  - SEO
  - Influencer Marketing
  - Web Development & UI/UX
  - Production
  - Branding & Creative
- **Action:** Check one category (or more)

## 🖼️ How to Add Images - Detailed Steps

### Method 1: Using "Select Image" Button (Easiest)

1. Click **"Select Image"** button next to "Image 1 URL"
2. WordPress Media Library opens
3. **Option A:** Choose existing image
   - Click on an image
   - Click **"Select"** button
4. **Option B:** Upload new image
   - Click **"Upload Files"** tab
   - Drag & drop image OR click "Select Files"
   - Choose your image
   - Click **"Select"** button
5. The image URL will automatically fill in the field

### Method 2: Manual URL Entry

1. Upload image to WordPress Media Library first
2. Go to **Media** → **Library**
3. Click on your image
4. Copy the **"File URL"** from the right sidebar
5. Paste it into the "Image 1 URL" field

---

## 🎯 Quick Checklist

When adding a work, make sure you fill:

- [ ] **Title** (top field) - Required
- [ ] **Description/Tagline** (Work Details box) - Required
- [ ] **Image 1 URL** (Work Details box) - Required
- [ ] **Image 1 Alt Text** (Work Details box) - Recommended
- [ ] **Category** (right sidebar) - Required
- [ ] **Featured** checkbox (Work Details box) - Check if you want on home page
- [ ] **Order** (Work Details box) - Recommended (use 1, 2, 3...)

---

## 💡 Tips

- **Image Size:** Recommended 534x300 pixels (but any size works)
- **Image Format:** JPG, PNG, or WebP
- **Featured:** Only check if you want it on the home page
- **Order:** Use 1, 2, 3... Lower numbers appear first
- **Category:** Select at least one category

---

## 🆘 Can't Find "Work Details" Box?

If you don't see the "Work Details" box:
1. Look at the top right of the editor
2. Click **"Screen Options"** (top right)
3. Make sure **"Work Details"** is checked
4. The box should appear below the main editor

---

**That's it! Fill these fields and click "Publish"!** 🎉
