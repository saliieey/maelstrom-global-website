# 📝 How to Add More Works in WordPress

## 🎯 Step-by-Step Guide

### Step 1: Go to WordPress Admin

1. **Log into WordPress:** `https://maelstromglobal.in/wp-admin`
2. **Click "Works"** in the left sidebar
3. **Click "Add New"**

---

## 📋 Fill in These Fields

### **Top Section - Title**
- **Field:** Big text box at the top
- **What to enter:** Your work title
- **Example:** "Partnering with [Client Name]"

---

### **Work Details Box** (Scroll down to find this)

#### 1. **Description/Tagline**
- **Field:** "Description/Tagline" text box
- **What to enter:** Short tagline or description
- **Example:** "Where modern care meets confident smiles"
- **Purpose:** Shows below the title on your website

#### 2. **Image 1 URL**
- **Field:** "Image 1 URL" with "Select Image" button
- **What to do:**
  1. Click **"Select Image"** button
  2. WordPress media library opens
  3. **Option A:** Choose existing image
  4. **Option B:** Upload new image
     - Click **"Upload Files"** tab
     - Drag image OR click **"Select Files"**
     - Choose your image
  5. Click **"Select"** button
  6. URL fills automatically
- **Purpose:** Main image shown on website

#### 3. **Image 1 Alt Text**
- **Field:** "Image 1 Alt Text" text box
- **What to enter:** Description of the image
- **Example:** "[Client Name] Campaign Image"
- **Purpose:** For accessibility (screen readers)

#### 4. **Image 2 URL** (Optional)
- **Field:** "Image 2 URL" with "Select Image" button
- **What to do:** Same as Image 1 (optional - can leave blank)
- **Purpose:** Secondary image (if you have one)

#### 5. **Image 2 Alt Text** (Optional)
- **Field:** "Image 2 Alt Text" text box
- **What to enter:** Description of second image (if you added Image 2)

#### 6. **Featured**
- **Field:** Checkbox "Show on home page"
- **What to do:** ✅ **Check this box**
- **Purpose:** Makes it appear on home page "Our Works" section

#### 7. **Order**
- **Field:** "Order" number box
- **What to enter:** Number for sorting
- **Examples:**
  - First work: `1`
  - Second work: `2`
  - Third work: `3`
- **Purpose:** Lower numbers appear first

---

### **Right Sidebar - Category**

#### **Categories**
- **Field:** Checkboxes in right sidebar
- **What to do:** ✅ Check ONE category
- **Options:**
  - Social Media
  - Performance Marketing
  - SEO
  - Influencer Marketing
  - Web Development & UI/UX
  - Production
  - Branding & Creative

---

## ✅ Example - Adding Your Second Work

**Title (top):**
```
Partnering with [Your Client Name]
```

**Work Details Box:**
- **Description/Tagline:** `Your tagline here`
- **Image 1 URL:** Click "Select Image" → Choose/Upload image
- **Image 1 Alt Text:** `[Client Name] Campaign`
- **Image 2 URL:** (Leave blank or add second image)
- **Featured:** ✅ Check the box
- **Order:** `2`

**Right Sidebar:**
- **Category:** ✅ Check one (e.g., "Branding & Creative")

**Then click "Publish"**

---

## ✅ Example - Adding Your Third Work

**Title (top):**
```
Partnering with [Another Client Name]
```

**Work Details Box:**
- **Description/Tagline:** `Another tagline`
- **Image 1 URL:** Click "Select Image" → Choose/Upload image
- **Image 1 Alt Text:** `[Client Name] Campaign`
- **Featured:** ✅ Check the box
- **Order:** `3`

**Right Sidebar:**
- **Category:** ✅ Check one

**Then click "Publish"**

---

## 📝 Quick Checklist for Each Work

- [ ] **Title** entered (top field)
- [ ] **Description/Tagline** filled
- [ ] **Image 1** selected/uploaded
- [ ] **Image 1 Alt Text** filled
- [ ] **Featured** checkbox checked ✅
- [ ] **Order** number set (2, 3, etc.)
- [ ] **Category** selected
- [ ] **Publish** button clicked

---

## 🎯 Important Notes

1. **Featured:** Must check this box for works to appear on home page
2. **Order:** Use 2, 3, 4... for new works
3. **Image Size:** Recommended 534x300 pixels (but any size works)
4. **Category:** Select at least one category

---

## 🖼️ Image Tips

- **Format:** JPG, PNG, or WebP
- **Size:** Any size works, but 534x300px is recommended
- **Quality:** Use high-quality images
- **Naming:** Use descriptive filenames (e.g., `client-name-campaign.jpg`)
