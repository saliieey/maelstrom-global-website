## ✅ Quick Copy-Paste Template

**For each new work, fill this:**

```
Title: Partnering with [Client Name]

Description/Tagline: [Your tagline here]

Image 1: [Click "Select Image" and upload]

Image 1 Alt Text: [Client Name] Campaign

Featured: ✅ CHECK THIS BOX

Order: [2, 3, 4, etc.]

Category: ✅ Select one category
```

---

## 🎯 Step-by-Step for Each Work

1. **Go to:** Works → Add New
2. **Title:** Type your work title
3. **Scroll down** to "Work Details" box
4. **Description:** Type tagline
5. **Image 1:** Click "Select Image" → Upload
6. **Alt Text:** Type image description
7. **Featured:** ✅ Check box
8. **Order:** Type number (2, 3, etc.)
9. **Category:** Check one (right sidebar)
10. **Click:** "Publish"
