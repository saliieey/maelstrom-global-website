# Super Simple Guide - Adding a Work

## ✅ What You've Done So Far
- ✅ Added Title: "Partnering with Amend Dental"
- ✅ Added Description: "test description work"

**Good! Now you need to add the image and other details.**

---

## 🎯 What to Do Next - Step by Step

### Step 1: Scroll Down Below the Content Editor

**Look BELOW the text editor** (where you typed "test description work")

You should see a box called **"Work Details"** - this is where you add images!

**If you DON'T see "Work Details" box:**

1. Look at the **TOP RIGHT** of your screen
2. Find **"..." (three dots)** or **"Options"** button
3. Click it
4. Look for **"Preferences"** or **"Editor Settings"**
5. Make sure **"Work Details"** is checked/enabled

---

### Step 2: Find "Work Details" Box

**Scroll down** below the content editor. You should see:

```
┌─────────────────────────────────┐
│ Work Details                    │
├─────────────────────────────────┤
│ Description/Tagline:            │
│ [text box]                      │
│                                 │
│ Image 1 URL:                    │
│ [text box] [Select Image]       │
│                                 │
│ Image 1 Alt Text:               │
│ [text box]                      │
│                                 │
│ Featured: ☐ Show on home page   │
│                                 │
│ Order: [1]                      │
└─────────────────────────────────┘
```

---

### Step 3: Fill in "Work Details" Box

**Inside the "Work Details" box:**

1. **Description/Tagline:**
   - Type: "Where modern care meets confident smiles"
   - (This is different from the main description)

2. **Image 1 URL:**
   - Click the **"Select Image"** button
   - WordPress will open media library
   - Click **"Upload Files"** tab
   - Drag an image OR click **"Select Files"**
   - Choose your image
   - Click **"Select"** button
   - The URL will fill automatically

3. **Image 1 Alt Text:**
   - Type: "Amend Dental Campaign"

4. **Featured:**
   - ✅ Check the box "Show on home page"

5. **Order:**
   - Type: `1`

---

### Step 4: Right Sidebar - Category

**Look at the RIGHT SIDEBAR:**

1. Find **"Categories"** section
2. Check one box, for example:
   - ✅ **"Branding & Creative"**

---

### Step 5: Publish

**Top Right Corner:**
1. Click **"Publish"** button (blue button)
2. Done! ✅

---

## 🆘 If You Still Don't See "Work Details" Box

### Option A: Enable Screen Options

1. Look at **TOP RIGHT** of the page
2. Find **"..." (three dots menu)** or **"Options"**
3. Click it
4. Look for **"Work Details"** checkbox
5. ✅ Check it
6. The box should appear!

### Option B: Use Classic Editor

If you're using block editor and can't find it:

1. Install "Classic Editor" plugin (optional)
2. OR just scroll down more - the box might be collapsed
